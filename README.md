# Projets d'Automatisation et Capteurs Arduino

Ce dépôt regroupe deux projets électroniques pratiques d'automatisation et de surveillance environnementale.

---

## 1. Abri Automatique Anti-Pluie pour Vêtements

### Description
Système automatisé permettant d'abriter du linge étendu dès le début d'une averse. Le système utilise un capteur de pluie / niveau d'eau et actionne un servomoteur pour recouvrir la zone d'étendage.

### Démonstration Vidéo
🎥 ** Voir la démonstration vidéo de l'abri anti-pluie sur YouTube : https://youtu.be/c6GL7eh7HZ0?si=BnUFDzoH-ToqrPrN **

### Composants principaux
* Carte Arduino
* Capteur de pluie / Niveau d'eau
* Servomoteur

---

## 2. Détecteur d'Humidité du Sol

### Description
Système de surveillance de l'état d'hydratation de la terre. Le capteur mesure en temps réel le niveau d'humidité du sol pour indiquer s'il est sec ou suffisamment arrosé (utile pour l'arrosage automatique de plantes).

### Démonstration Vidéo
🎥 ** Voir la démonstration vidéo du détecteur d'humidité sur YouTube : https://youtu.be/sttMqekd8K8?si=0lZr0WxOP3HZey8b **

### Composants principaux
* Carte Arduino
* Capteur d'humidité du sol (hygromètre)
* Témoins lumineux (LEDs) / Buzzer
